# Humans are responsible just above the code level

Verified: 3 verbatim quotes from 1 source

Dimension: Roles for humans (human-roles)

Evidence: opinion

How to measure: Compare lead time and escaped defects for changes signed off through architecture inspection and hands-on use with changes that went through full code review.

Agents cannot be held responsible, so humans must sign off on what they produce. Martin argues they should do this by checking architecture, partitioning and deployability and by using the running system, not by reviewing code line by line, which he says slows everything down and adds little.

## Quotes

> The agents are not responsible for anything. They're entirely irresponsible. Only humans can be responsible, at the moment and probably over the next several years.
>
> [Uncle Bob: Why I Stopped Reading Code and Building Harnesses | Aviator](https://www.aviator.co/podcast/uncle-bob-martin-ai-clean-code)

> I'm going to make sure that the system is deployable and rational, without devolving all the way down to reviewing the code. Reviewing the code isn't very useful anymore, and it slows everything down like crazy.
>
> [Uncle Bob: Why I Stopped Reading Code and Building Harnesses | Aviator](https://www.aviator.co/podcast/uncle-bob-martin-ai-clean-code)

> Somehow we humans have to take responsibility for the systems at just above the code level. Leave the syntax to the agents, but everything else we still hold near and dear to our hearts, and we are responsible.
>
> [Uncle Bob: Why I Stopped Reading Code and Building Harnesses | Aviator](https://www.aviator.co/podcast/uncle-bob-martin-ai-clean-code)
