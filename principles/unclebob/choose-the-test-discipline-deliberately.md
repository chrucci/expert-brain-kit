# Choose the test discipline deliberately

Verified: 2 verbatim quotes from 1 source

Dimension: Processes (processes)

Evidence: measurement

How to measure: Under each discipline, record examples, assertions per example, line coverage, program size and function count.

The test discipline prescribed for agents (TDD's three laws, test-last, function-then-test, or none) measurably changed the number and density of tests and the size and shape of the program itself. Picking one is a real design decision for the team.

## Quotes

> How you test changes the **size and shape of the suite** — examples, assertions, and how densely they pack — and, when you actually write the program again, the **size and shape of the Hunt**.
>
> [negative-test-experiment/experiment-summary.md at main · unclebob/negative-test-experiment](https://github.com/unclebob/negative-test-experiment/blob/main/experiment-summary.md)

> Test-last packs \~8 checks into each example; bundling writes many small ones (\~2 each).
>
