# Measure token spend on the way up, then waste and outcomes

Verified: 7 verbatim quotes from 3 sources

Dimension: Metrics (metrics)

Evidence: measurement

How to measure: Track daily token spend per engineer against the 15M threshold, then outcomes delivered per token above it, with cost attributed per run and reconciled to the bill.

Token spend shows how much people are actually practising with agents and finding new bottlenecks, up to roughly 15M tokens a day. Past that point, measure waste and outcomes per token, tie budget increases to real results, and collect per-turn cost telemetry by run so spend can be attributed accurately.
