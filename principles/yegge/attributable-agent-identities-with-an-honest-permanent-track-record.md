# Attributable agent identities with an honest, permanent track record

Verified: 8 verbatim quotes from 9 sources

Dimension: Metrics (metrics)

Evidence: opinion

How to measure: Track the share of agent work attributed to a specific agent identity and owner, and whether routing on per-agent completion and reopen history lowers rework compared with random assignment.

Every commit, ticket change and event should name the specific agent that did it and the human who owns it. Keep an append-only, never-falsified ledger of completions, reopens, cost and independently validated quality. Use it to debug, compare models, route work and widen or narrow trust based on evidence rather than claims. Run the organisation blame-free so that agents aren't pushed into costly self-protective re-verification.
