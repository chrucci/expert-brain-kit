# Route work to the cheapest capable model; the strong model designs and reviews

Verified: 8 verbatim quotes from 5 sources

Dimension: Tools (tools)

Evidence: experience

How to measure: Compare cost per completed task and rework rates under tiered routing against single-model staffing, and count saved hard tasks each new model solves.

Tag work by how much intelligence it needs. Have the strongest model plan, coordinate and review, and send implementation to cheaper models, sub-agents and tools. Treat token spend as a core engineering concern: hand off earlier, use smaller tasks and watch the cache. Rerun a private set of tasks your current models fail at whenever a new model comes out.
