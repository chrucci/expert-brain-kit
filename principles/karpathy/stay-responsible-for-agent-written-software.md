# Stay responsible for agent-written software

Verified: 5 verbatim quotes from 2 sources

Dimension: Processes (processes)

Evidence: experience

How to measure: Track vulnerability and defect rates on agent-written production code, and on accepted AI completions, against the team's pre-agent baseline while measuring delivery speed.

Agents make you faster, but you still own the software and can't ship vulnerabilities because you vibe coded it. Agentic engineering keeps the professional quality bar by reviewing diffs and building specs, tests, permissions and evaluation loops around the agents.
