# Make software and infrastructure legible to agents

Verified: 4 verbatim quotes from 2 sources

Dimension: Emerging ideas (emerging)

Evidence: experience

How to measure: Measure the share of delivery time spent on manual console and click-through steps, and agent task completion before and after converting them to commands.

Once agents write the code, much of the remaining work sits in dashboards and click-through steps such as keys, DNS and OAuth that agents can't see or change. Expect this to become the bottleneck, and turn docs, interfaces and configuration into text and commands an agent can read and act on.
