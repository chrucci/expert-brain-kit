# Agents amplify experience, and the skill is built by visible practice

Verified: 8 verbatim quotes from 10 sources

Dimension: Skills (skills)

Evidence: experience

How to measure: Compare acceptance, rework and defect rates of agent-assisted work across engineers by experience, practice time and exposure to shared agent sessions.

Using coding agents well is hard. It amplifies existing engineering judgement and raises the bar for discipline, and its core skill is instructing agents confidently and verifying their changes confidently. Teams build that skill through deliberate practice: low-risk side projects, prompting in shared channels, and a growing stock of proven techniques and capabilities such as advanced Git.
