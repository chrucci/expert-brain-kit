# Judge output by real use and quality, not artefacts

Verified: 5 verbatim quotes from 3 sources

Dimension: Metrics (metrics)

Evidence: experience

How to measure: Compare post-adoption defects for dogfooded components against ones accepted on coverage and docs alone, and track merged tested lines per engineer alongside defect and maintenance rates.

Agents can generate commits, READMEs and full test coverage in minutes, so those artefacts no longer signal care. Better signals are sustained real use and internal-user retention, and lines of code count as productivity only while quality is held constant.
