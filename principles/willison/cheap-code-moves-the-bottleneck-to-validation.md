# Cheap code moves the bottleneck to validation

Verified: 8 verbatim quotes from 5 sources

Dimension: Processes (processes)

Evidence: experience

How to measure: Measure where work waits across design, build, review and release, and count alternatives prototyped per feature or decision against how often decisions are later reversed.

Initial working code now costs almost nothing, so cost-based habits across the lifecycle need rethinking. Teams should prototype several options in parallel, test technology choices with agent-built load tests, try low-value ideas in async sessions, take more design risk, and put their effort into proving which option is right.
