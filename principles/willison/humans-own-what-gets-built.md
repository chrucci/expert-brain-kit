# Humans own what gets built

Verified: 8 verbatim quotes from 6 sources

Dimension: Roles for humans (human-roles)

Evidence: experience

How to measure: Measure time agent-built work waits on decisions, and compare rework and abandonment for human-architected components against agent-architected ones.

Agents handle implementation well but not coherent architecture or product taste. Humans own the choice of what code to write, the architecture, whether the product is good, and the discipline that protects conceptual integrity when features are cheap. Engineers who can make product calls themselves avoid the new bottleneck of waiting on decisions, and agents let people in high-interruption roles contribute code again.
