# Don't read benchmark scores as real-world impact

Verified: 2 verbatim quotes from 1 source

Dimension: Metrics (metrics)

Evidence: opinion

How to measure: Compare the speedup predicted from benchmark scores or vendor claims with the speedup measured in a randomized trial on the team's own backlog.

Benchmarks use self-contained, automatically scored tasks that need little context. That can overstate or understate what a model delivers on messy real work, so treat scores as one input and check claims against real tasks in the environment where the tool will be used.

## Quotes

> benchmarks may overestimate model capabilities by only measuring performance on well-scoped, algorithmically scorable tasks.
>
> [Measuring the Impact of Early-2025 AI on Experienced Open-Source Developer Productivity](https://metr.org/blog/2025-07-10-early-2025-ai-experienced-os-dev-study/)

> There are meaningful tradeoffs between methods, and it will continue to be important to develop and use diverse evaluation methodologies to form a more comprehensive picture of the current state of AI, and where we’re heading.
>
> [Measuring the Impact of Early-2025 AI on Experienced Open-Source Developer Productivity](https://metr.org/blog/2025-07-10-early-2025-ai-experienced-os-dev-study/)
