# Harness engineering is a core programmer skill

Verified: 2 verbatim quotes from 1 source

Dimension: Skills (skills)

Evidence: opinion

How to measure: Track engineering time spent on guides and sensors, and whether review rejections and test failures on agent output drop as a result.

Fowler sees work on the guides and sensors around the LLM as central to programming with agents. Guides include saved guideline documents fed into prompts. Teams should build this skill and give time to maintaining the harness.
