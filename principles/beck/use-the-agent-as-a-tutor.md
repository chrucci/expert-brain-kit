# Use the agent as a tutor

Verified: 3 verbatim quotes from 1 source

Dimension: Skills (skills)

Evidence: experience

Engineers should act on their curiosity and use the agent as a patient tutor for concepts they don't understand. That learning adds optionality and makes the next feature easier, even when nothing ships.
