# Replace the starter work juniors used to learn on

Verified: 2 verbatim quotes from 1 source

Dimension: Skills (skills)

Evidence: opinion

How to measure: Track how quickly junior engineers reach independent ownership of components, before and after agent adoption.

Juniors once grew through real but low-risk work, like making a senior's tests pass, and agents now take that work. Teams have to deliberately create new paths for junior engineers to learn.

## Quotes

> So, one way to think about this is a junior programmer is, you know, senior programmer writes some tests and the junior programmer goes and makes 'em pass or whatever.
>
> [O11ycast | Ep. #80, Augmented Coding with Kent Beck | Heavybit](https://www.heavybit.com/library/podcasts/o11ycast/ep-80-augmented-coding-with-kent-beck)

> There's going to be a generation of native augmented coders, and they are going to be so much better than we are at using these tools that we won't be able to understand even how they're working.
>
> [O11ycast | Ep. #80, Augmented Coding with Kent Beck | Heavybit](https://www.heavybit.com/library/podcasts/o11ycast/ep-80-augmented-coding-with-kent-beck)
