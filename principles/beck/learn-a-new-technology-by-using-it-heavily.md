# Learn a new technology by using it heavily

Verified: 8 verbatim quotes from 5 sources

Dimension: Skills (skills)

Evidence: opinion

How to measure: Track how many tools or practices the team trials each quarter and how often a trial changes the team's defaults.

New technology is first understood through old frames, and nobody yet knows the right tools or practices for agent work. Teams need explorers who try every cheap tool and practice, bring curiosity and play, and keep what works, and leaders should teach people how to find answers instead of handing them out.
