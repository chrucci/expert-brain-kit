# Decide which game you are playing before choosing a method

Verified: 2 verbatim quotes from 1 source

Dimension: Processes (processes)

Evidence: opinion

How to measure: Label each project as one-off or long-lived up front, then compare rework or rewrite rates for spec-driven agent work on each kind.

Whether spec-driven development fits depends on what the software is for. A one-off job that ends when it works needs different practices from a system that has to keep paying for its own next step, so settle that first.

## Quotes

> Spec-driven or not spec-driven is *not* the question. The first question is, “What game are we playing?”
>
> [Earn *And* Learn](https://newsletter.kentbeck.com/p/earn-and-learn)

> The hidden assumption behind this style of spec-driven development is that we’re playing The Finish Line Game.
>
> [Earn *And* Learn](https://newsletter.kentbeck.com/p/earn-and-learn)
