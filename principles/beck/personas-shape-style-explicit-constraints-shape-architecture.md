# Personas shape style; explicit constraints shape architecture

Verified: 3 verbatim quotes from 1 source

Dimension: Techniques (techniques)

Evidence: experience

How to measure: Run the same task with persona-only, constraints-only and combined prompts and compare structure, test granularity and naming.

Telling an agent to act like an expert improves naming and testing habits but not structural design. To get a particular architecture, state the design decisions outright, and combine both for the best result.

## Quotes

> It made the code “feel” better but didn’t change the fundamental structural decisions.
>
> [Taming the Genie: "Like Kent Beck"](https://newsletter.kentbeck.com/p/taming-the-genie-like-kent-beck)

> I added explicit constraints: “Use the Composite pattern. Break behavior into small, specialized classes.”
>
> [Taming the Genie: "Like Kent Beck"](https://newsletter.kentbeck.com/p/taming-the-genie-like-kent-beck)

> It produced a finer-grained design even without the persona.
>
> [Taming the Genie: "Like Kent Beck"](https://newsletter.kentbeck.com/p/taming-the-genie-like-kent-beck)
