# Ask the agent instead of writing docs that go stale

Verified: 3 verbatim quotes from 1 source

Dimension: Processes (processes)

Evidence: opinion

How to measure: Compare how long it takes to answer real questions about the code by asking an agent versus searching docs and ADRs, and how often stored docs are out of date.

Agents weaken the case for documentation and ADRs. Keep the code simple and let people ask the agent about the source when they need answers, instead of generating documents that will go out of date.
