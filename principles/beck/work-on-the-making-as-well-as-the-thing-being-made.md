# Work on the making as well as the thing being made

Verified: 2 verbatim quotes from 1 source

Dimension: Techniques (techniques)

Evidence: experience

How to measure: Version the agent rule and prompt files and track whether each revision changes rework or rollback rates.

While building, keep refining the prompts, rules and workflows you build with. Best practices are unknown, so advancing the workflow is worth more than maximizing output right now.
