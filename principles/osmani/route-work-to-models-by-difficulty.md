# Route work to models by difficulty

Verified: 3 verbatim quotes from 2 sources

Dimension: Tools (tools)

Evidence: opinion

How to measure: Compare token cost per merged feature and defect rates before and after routing routine tasks to a smaller model.

Send routine work such as formatting, documentation, git operations, test generation and CI checks to a fast, cheap model, and keep the strong model for debugging, security and design. Model routing is a cost lever that keeps quality steady.

## Quotes

> can send lighter tasks (formatting, documentation, git operations) to a faster model and reserve a stronger model for cognitively demanding work (debugging, security auditing, interface design).
>
> [agent-skills: docs/advanced-per-agent-configuration.md](https://github.com/addyosmani/agent-skills/blob/main/docs/advanced-per-agent-configuration.md)

> Route the hard reasoning to a big model and the routine work, test generation, code review, CI checks, to a small cheap one. The quality holds and the bill comes down.
>
> [The New Software Lifecycle | AddyOsmani.com](https://addyosmani.com/blog/new-sdlc-vibe-coding/)

> the part I want developers to take away is that context engineering and model routing are financial levers, not just technical ones.
>
> [The New Software Lifecycle | AddyOsmani.com](https://addyosmani.com/blog/new-sdlc-vibe-coding/)
