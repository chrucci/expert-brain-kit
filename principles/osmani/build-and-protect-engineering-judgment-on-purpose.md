# Build and protect engineering judgment on purpose

Verified: 8 verbatim quotes from 10 sources

Dimension: Skills (skills)

Evidence: measurement

How to measure: Run periodic comprehension or debugging checks and compare engineers who mainly use agents for explanation with those who mainly delegate generation.

Engineers who hand generation to agents understand the result measurably less well. Those who use agents to ask questions and get explanations keep their skills. Agents now take the reps that used to build judgment, so juniors need deliberate practice: form a hypothesis first, read diffs, log agent mistakes and code some features by hand. Teams should invest in the skills whose value is rising: decomposition, spec writing, evaluation and domain expertise.

## Quotes

> if you’re junior and you lean on AI before building those fundamentals, you risk a dangerous skill atrophy.
>
> [Agentic Engineering | AddyOsmani.com](https://addyosmani.com/blog/agentic-engineering/)

> And within the AI group, the strong results came from those who asked conceptual questions and requested explanations rather than treating the model as a code vending machine.
>
> [Agentic Skill Decay](https://addyosmani.com/blog/agentic-skill-decay/)

> The same tool, used to interrogate rather than to produce, builds rather than erodes your mental model.
>
> [Cognitive Surrender | AddyOsmani.com](https://addyosmani.com/blog/cognitive-surrender/)

> Research suggests that developers using AI for code generation delegation score below 40% on comprehension tests, while developers using AI for conceptual inquiry - asking questions, exploring tradeoffs - score above 65%.
>
> [Comprehension Debt - the hidden cost of AI generated code. | AddyOsmani.com](https://addyosmani.com/blog/comprehension-debt/)

> Engineers who used AI to ask conceptual questions scored above 65%. Engineers who copy-pasted the generated code scored under 40%. **The tool didn’t determine the outcome. The posture did.**
>
> [Don't Outsource the Learning | AddyOsmani.com](https://addyosmani.com/blog/dont-outsource-learning/)

> Taste used to be a byproduct of the reps. Agents took the reps. So if you’re junior you now have to go get the taste (and judgment) on purpose.
>
> [Earning taste and judgment](https://addyosmani.com/blog/earning-judgment/)

> Knowing how to break a large, ambiguous goal into well-scoped subtasks that an agent can execute reliably. Tasks that are too large tend to go off-track.
>
> [The Factory Model: How Coding Agents Changed Software Engineering | AddyOsmani.com](https://addyosmani.com/blog/factory-model/)

> Defining work crisply enough that an agent can run for a day on it is harder than doing the work yourself. The skill that’s appreciating in value isn’t writing code. It’s writing specs that survive contact with an autonomous executor.
>
> [Long-running Agents | AddyOsmani.com](https://addyosmani.com/blog/long-running-agents/)
