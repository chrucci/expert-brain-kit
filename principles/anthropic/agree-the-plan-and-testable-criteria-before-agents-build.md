# Agree the plan and testable criteria before agents build

Verified: 8 verbatim quotes from 7 sources

Dimension: Processes (processes)

Evidence: experience

How to measure: Compare first-pass acceptance and rework for agent changes that started from a committed plan or spec with testable criteria against those that did not, and track how much of a roadmap is still valid at its midpoint.

Put the human back-and-forth into planning: work out the approach in plan mode or a spec interview, fix testable done criteria, and commit the plan or spec, preferably in code form such as tests or mockups. Then hand execution to the agent and give the same artifacts to the verifier. At the organisation level, short prototype-and-feedback cycles replace long roadmaps that agent speed makes obsolete.
