# Protect the skills humans need to oversee agents

Verified: 8 verbatim quotes from 2 sources

Dimension: Skills (skills)

Evidence: measurement

How to measure: Give engineers periodic debugging and code-reading assessments and correlate scores with delegation-style versus comprehension-style agent use and with defects caught in review.

Learning new material by delegating to AI cut comprehension, especially debugging, with no real speed gain, while using the agent to ask questions and get explanations preserved mastery. Managers should design norms so engineers keep learning, use agents for onboarding questions, and weight debugging, code reading and conceptual understanding over syntax.
