# Owning engineers set the shipping conditions

Verified: 2 verbatim quotes from 1 source

Dimension: Roles for humans (human-roles)

Evidence: opinion

How to measure: Check whether owning or on-call engineers sign off on the rules for AI-generated changes in their systems, and assess how fluent those engineers are with AI tools.

The engineers who support code in production should help define the conditions under which AI-generated code ships into their systems. Their pushback carries weight only if they have built real fluency with AI ways of working.
