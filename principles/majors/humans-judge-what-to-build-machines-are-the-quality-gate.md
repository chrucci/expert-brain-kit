# Humans judge what to build; machines are the quality gate

Verified: 6 verbatim quotes from 2 sources

Dimension: Roles for humans (human-roles)

Evidence: opinion

How to measure: Classify review comments as product/design or syntax/bug, and compare defects caught by human review with those caught by automated checks on the same changes.

Humans are the weakest link at repetitive validation, so teams should not defend human value as the final check on agent output. Human review should go to whether a change belongs in the product, whether the mental model holds together and whether the API is well designed. Syntax and bug checking should be automated.
