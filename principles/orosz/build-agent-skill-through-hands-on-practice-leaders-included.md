# Build agent skill through hands-on practice, leaders included

Verified: 8 verbatim quotes from 5 sources

Dimension: Skills (skills)

Evidence: opinion

How to measure: Track the share of engineers and leaders using agents on real tasks, and compare throughput and rework before and after training or 'impossible goal' exercises.

Skill with AI coding tools varies widely and can be taught. Give every engineer the best models and an ambitious goal, and teach the skill deliberately. Have leaders use the tools themselves, and use team rituals to share what works and to set where humans must do all the work.
