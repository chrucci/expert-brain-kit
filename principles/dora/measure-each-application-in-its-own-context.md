# Measure each application in its own context

Verified: 2 verbatim quotes from 1 source

Dimension: Metrics (metrics)

Evidence: opinion

How to measure: Check that metrics are reported per service rather than as organisation-wide averages and that every function sees the same set.

Apply delivery metrics to one application or service at a time, because blending or comparing very different systems misleads. Share the same metrics across development, operations and release so delivery is owned jointly.

## Quotes

> These metrics are meant to be applied at the application or service level. Comparing metrics between vastly different applications (for example, a mobile app and a mainframe system) can be misleading.
>
> [DORA | DORA’s software delivery performance metrics](https://dora.dev/guides/dora-metrics/)

> Sharing all five metrics across development, operations, and release teams fosters collaboration and shared ownership of the delivery process. Isolating teams with specific metrics can lead to friction and finger-pointing.
>
> [DORA | DORA’s software delivery performance metrics](https://dora.dev/guides/dora-metrics/)
