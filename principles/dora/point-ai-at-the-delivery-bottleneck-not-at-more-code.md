# Point AI at the delivery bottleneck, not at more code

Verified: 2 verbatim quotes from 1 source

Dimension: Processes (processes)

Evidence: measurement

How to measure: Measure wait time at each value-stream stage, such as review queue time, before and after applying AI there, and compare with end-to-end lead time.

Faster code generation doesn't speed up delivery when review, testing and integration are the constraint. Map the value stream and use AI to relieve the real bottleneck, because extra generated code only lengthens the queue.
