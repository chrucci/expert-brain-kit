# Hire for knowing where AI tools help, and use them for throwaway prototypes

Verified: 2 verbatim quotes from 1 source

Dimension: Skills (skills)

Evidence: opinion

How to measure: Track the time from idea to working prototype and the share of prototypes thrown away before any production investment.

Engineers should be competent with AI tools, which means knowing where they help and where they don't, not using them for everything. Agents are especially worth using to produce disposable proofs of concept quickly, while production work stays much as it was.

## Quotes

> I would definitely require competency with AI tools. You don't need to use them for everything. That's not important to me, but it's an important tool to understand the edges of.
>
> [Mitchell Hashimoto’s new way of writing code at 01:42:59](https://newsletter.pragmaticengineer.com/p/mitchell-hashimoto?t=6179s)

> I would much rather someone just like throw slop at a wall that you're never going to ship and spend a day doing that.
>
> [Mitchell Hashimoto’s new way of writing code at 01:42:59](https://newsletter.pragmaticengineer.com/p/mitchell-hashimoto?t=6179s)
